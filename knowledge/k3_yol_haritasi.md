# UMAY AI OS — Geliştirme Yol Haritası

## Faz 1 — MVP (Şu An)
Temel L1 Kernel, L2 Altyapı, tek L4 ajan (System Agent). Hafıza: Stream + Working Memory.
**Hedef:** İlk çalışan demo.

## Faz 2 — Foundation
L6 Episodic Memory ve L3 Tool Platform entegrasyonu (Sandbox olmadan). Coding Agent ve Browser Agent eklenmesi.

## Faz 3 — Core
Tüm hafıza katmanları, Sandbox güvenliği, Zero Trust politikaları tam aktivasyon. L7 Performance Analyzer eklenmesi.

## Faz 4 — Advanced
Çoklu ajan haberleşmesi, gelişmiş DAG planlaması, Edge donanım testleri, L0→L1 donanım kesmeleri.

## Faz 5 — Autonomous & Enterprise
L7 Evolution Core tam devreye (Shadow Mode ile kendi kendini iyileştirme), otonom yönetim, UMAY Ağı entegrasyonu.

- Yeni Model: L2 Model Runtime'a ekle, L5 Model Router'a rota gir
- Çekirdek kod hiçbir ekleme için değiştirilmez (Plug & Play)
